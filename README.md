# Продуктовая воронка

Интерактивный калькулятор продуктовой воронки: моделируйте этапы, конверсии, маркетинговые метрики (CAC, LTV, ROMI, точка безубыточности) и приоритизируйте гипотезы (ICE / RICE).

Открыть: https://leonidbogachuk.github.io/voronka/voronka.html

## Возможности

- Конструктор воронки до 10 этапов: пилюли значений, слайдеры CR, замки этапов
- Пересчёт конверсий в двух режимах: изменять CR / сохранять CR
- Маркетинговые метрики: выручка, CAC, LTV, ROMI, LTV:CAC, CPL, ARPU, окупаемость, точка безубыточности
- Целевая выручка: расчёт нужных CR по этапам
- Сравнение периодов, сегментов и сценариев
- Приоритизация гипотез ICE / RICE с авторасчётом Reach и эффекта из данных воронки
- Сохранение сценариев, отмена/повтор (Ctrl+Z / Ctrl+Y)
- Экспорт: PDF, CSV, JSON, ссылка на воронку
- Тёмная и светлая тема

## Разработка

Один автономный файл `voronka.html` (Tailwind через CDN, без сборки). Данные хранятся в `localStorage` браузера.

```bash
# локальный запуск
start voronka.html
```

## Деплой

Сайт раздаётся через GitHub Pages из ветки `main`. Для обновления:

```bash
git add -A
git commit -m "описание изменений"
git push
```

Через пару минут изменения появятся на https://leonidbogachuk.github.io/voronka/voronka.html
